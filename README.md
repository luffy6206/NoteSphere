AI Exam Notes Generator 🚀

An AI-powered Exam Notes Generator built using the MERN Stack that helps students generate smart exam-oriented notes using Artificial Intelligence.

Currently under development ⚡

✨ Current Features

✅ Modern React UI
✅ Firebase Authentication
✅ JWT Authorization
✅ Responsive Design
✅ AI Notes Generation (In Progress)
✅ Notes Dashboard UI
✅ Protected Routes

🧠 Project Goal

The goal of this project is to build a real-world AI SaaS application that helps students:

Generate exam-focused notes
Create revision notes instantly
Improve concept understanding using AI
Save preparation time

⚙️ Setup Instructions
Clone Repository
git clone : https://github.com/luffy6206/NoteSphere.git
Frontend Setup
cd client
npm install
npm run dev
Backend Setup
cd server
npm install
npm run dev
🔑 Environment Variables

Create .env inside server/

PORT=5000

MONGO_URI=your_mongodb_uri

JWT_SECRET=your_secret
